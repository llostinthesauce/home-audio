# home-audio

[![CI](https://github.com/llostinthesauce/home-audio/actions/workflows/ci.yml/badge.svg)](https://github.com/llostinthesauce/home-audio/actions/workflows/ci.yml)

Two tools I built for listening at home.

| | |
|---|---|
| **[Apple Music Toolkit](music-toolkit/)** | Python and AppleScript tools for keeping a large lossless Apple Music library clean: audio fingerprinting, album completeness checks against MusicBrainz, tag and artwork repair, iCloud reconciliation, and classic iPod sync. |
| **[Cronos](cronos/)** | A one-page phone remote for a Sonos home theater, with one-tap sound presets and an advanced mix panel. Built for a family member who hates the Sonos app. |

Each folder has its own README with setup instructions. Both are MIT licensed.
